# 부록 C — 3-1B 자료 찾아보기

> **이 부록의 한 줄**
> 3-1B의 모든 실습 폴더가 이 책의 몇 장에서 다뤄지는지 한 표로 찾는다. 폴더 이름을 누르면 원자료로, 장 이름을 누르면 해당 장으로 간다.

수업 날짜(Day) 순서로 정리했다. 난이도는 1~4단계다. 단계가 높을수록 설치 · 설정이 많다(3-1B 목록의 별 개수와 같다). **경로 고정** 표시가 있는 폴더는 덱 · 프롬프트 안에 자기 경로가 들어 있어 이름을 바꾸지 않는다.

# 자동차 산업 특화 데이터 검증 규칙

1. 기준시점: 연도, 월, 날짜와 연간/누계/월간을 표시.
2. 정의: `신규등록`과 `판매/인도/출하/생산`을 혼용 금지.
3. 단위: `대`, `천 대`, `십억 원`, `백만 달러`, `%`를 명시.
4. 비교: 그룹별 회계연도, 환율, 연결/별도, BEV/PHEV 포함 범위 정렬.
5. VOC/센서: 가상일 경우 실제 회사의 고객/설비 성과라고 표현 금지.
6. 센서: 이상치 탐지→오류 가능성·운영 맥락 확인→담당자 확인/조치 기록.
7. 관계: OEM/공장/협력사/기술 간 소유, 공급, 납품 추정, 전략 제휴 등을 혼동 금지.
8. 지식그래프 에지: `source_url`, `as_of_date`, `evidence_excerpt`, `confidence`, `status=verified|unverified`를 제안.
9. 시각화: 막대 기준선은 0, 축의 기간 일치, 비율 합계와 분모 확인.
10. 확인되지 않은 공개정보는 빈칸이나 `미확인`으로 표시하며 AI에게 만들라고 하지 말 것.

참고 저장소 `data/README.md`에 실제/가상/템플릿 구분 및 통계 정의가 상세히 기술되어 있음.

# Claude Code × GitHub: 초보자 실습 패키지

## 이 패키지 사용법
1. `01_초보자_실습가이드.md`를 Obsidian 또는 메모장으로 연다.
2. **처음 연결하는 수강생은 먼저 `02_브라우저_인증_초보자_가이드.md`를 읽고**, `prompts/E_브라우저_인증_도우미.txt`를 클코에 붙여넣는다.
3. 자료를 올릴 컴퓨터 폴더에서 Claude Code를 실행한다.
4. 새 저장소라면 `prompts/A_새_저장소_전체자동화.txt`, 기존 저장소라면 `prompts/B_기존_저장소_안전업데이트.txt`를 복사해 넣는다.
5. 로그인/도구 설치/업로드 예정 목록은 직접 확인 후 승인한다.
6. 실제 업로드 완료 뒤 새 파일 수정은 `prompts/C_반복업데이트.txt`로 처리한다.

## 파일 설명
- `01_초보자_실습가이드.md`: **브라우저 인증 5단계를 포함한** 전체 안내, 안전 지침, 검증, 오류 해결
- `02_브라우저_인증_초보자_가이드.md`: 초보자 인증 화면 안내, 보안 체크, 인증 취소 및 강사 멘트
- `prompts/E_브라우저_인증_도우미.txt`: 인증을 한 단계씩 도와주는 Claude Code 프롬프트
- `prompts/*.txt`: 클코에 바로 붙여넣는 프롬프트
- `sample_repository/`: 샘플 저장소 폴더 구조와 README / .gitignore / CLAUDE.md

**중요:** 샘플 저장소는 예시입니다. 실제 강의자료는 사용자가 직접 올릴 폴더에 있으며, 프롬프트가 해당 원본을 보존하도록 지시합니다. 비밀번호·고객 자료·계약 문서는 업로드하지 마세요. 

공식 문서: https://cli.github.com/manual/gh_repo_create , https://cli.github.com/manual/gh_auth_login

## 브라우저 인증 보안 핵심
인증코드·비밀번호·토큰을 수강생, 강사, 단체채팅에 공유하지 않습니다. 본인이 시작한 요청에만 동의하고, 앱 이름 및 접근 권한을 먼저 확인합니다. 인증 완료는 저장소 업로드 완료가 아닙니다.

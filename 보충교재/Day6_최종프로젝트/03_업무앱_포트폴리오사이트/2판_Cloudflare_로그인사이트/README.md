# 2판 — Cloudflare 로그인 사이트

저장소를 비공개로 두고 Cloudflare Pages로 배포한 뒤, 이메일 코드 로그인(Cloudflare Access)으로 허락한 사람만 들어오게 한다. 앱을 만드는 방법은 1판과 같다.

| 파일 | 내용 |
|---|---|
| `AX_App_Portfolio_Guide_Manual_2_Cloudflare` (.pptx · 공개본 .pdf) | 2판 가이드 매뉴얼 30장 |
| `ax-portfolio-template.zip` | 사이트 템플릿 (1판과 같은 파일) — 시작은 zip 안 `START_HERE_Cloudflare.md` |
| `Student_Beginner_Guide.md` | 초보자 가이드 — 11절이 2판 안내 (1판과 같은 파일) |

준비: GitHub 계정(github.com에서 무료 가입), Claude 데스크톱 앱(Pro 구독 · Code 탭), Cloudflare 계정(무료). 1판을 하지 않았어도 된다.

순서: 2판 매뉴얼을 보며 `START_HERE_Cloudflare.md`의 STEP 1~3을 붙여 넣는다. 앱을 더 붙이는 프롬프트도 2판 매뉴얼(22장)에 있다.

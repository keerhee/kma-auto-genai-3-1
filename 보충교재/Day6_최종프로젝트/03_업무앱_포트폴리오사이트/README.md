# 업무 앱 포트폴리오 사이트 만들기 (Day6 최종 프로젝트)

과정 6일 동안 만든 업무 앱(센서 점검, 리콜 분석, 대시보드 등)을 **사이트 하나에 카드로 모아** 주소 하나로 보여 주는 최종 프로젝트다. 프롬프트를 붙여 넣고 결과를 확인하면 Claude Code가 저장소 만들기 · 앱 붙이기 · 배포를 한다. 사이트 안에는 AI 안내원 "기어리"가 들어간다.

| 폴더 | 누가 보는 사이트 | 난이도 |
|---|---|---|
| `1판_GitHubPages_공개사이트/` | 누구나 보는 공개 사이트 (GitHub Pages) | ★★ |
| `2판_Cloudflare_로그인사이트/` | 허락한 동료만 이메일 코드로 들어오는 사이트 (비공개 저장소 + Cloudflare Access) | ★★★ |
| `강사용/` | 앱 9종 · 6일 스프린트 기획안 (공개하지 않음) | — |

두 판 모두 폴더 하나만으로 끝까지 진행할 수 있다. 사이트 템플릿 zip은 1판·2판 공용이며, `CLAUDE.md` 맨 위 "배포 방식" 한 줄로 고른다.

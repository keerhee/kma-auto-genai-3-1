## STEP 1 · 승인 ① — 업종과 핵심 질문을 정하고 교재 3장의 목차를 승인한다

- 누가: 나
- 어디: 내 컴퓨터 › Code › STEP 0의 세션 (폴더 shop-ax) › 입력칸 → 질문 카드

```
'소상공인 AX' 강의를 만들려고 해.
1. 질문 카드로 업종을 물어봐:
   카페·식당(기본) / 미용실 / 동네 소매점 / 직접 입력
2. brief.md 에 대상(소상공인과 예비 창업자),
   핵심 질문 한 문장, 결과물(교재 3장·덱·강의)을 적어 줘.
3. 교재 목차 3장을 표로 제안해 줘.
   칸: 핵심 질문 / 다룰 내용 / 필요한 자료 / 찾을 곳
4. 표를 보여 주고 질문 카드로 승인을 물어봐.
```

## STEP 2 · 승인 ② — 웹 검색으로 자료를 모으고 교재에 쓸 숫자를 확인한다

- 누가: 나
- 어디: 내 컴퓨터 › Code › 같은 세션 (폴더 shop-ax) › 입력칸 → 질문 카드

```
승인한 목차의 장마다 웹 검색으로 자료를 모아 줘.
1. 공개 자료만, 2025~2026년 자료를 먼저 쓴다.
   (중기부·소진공·소상공인24·중기중앙회·통계)
2. sources.md 에 번호·제목·기관·발행일·주소·
   신뢰도를 적는다. 장마다 출처 3개 이상.
3. 숫자는 원문 그대로, 못 찾으면 '미확보'.
4. 교재에 쓸 숫자만 facts.csv 로 뽑고, 출처가
   하나뿐인 숫자는 교차 확인한다.
장별 결과를 표로 보여 주고 승인을 물어봐.
```

## STEP 4 — 장마다 웹 검색으로 자료를 모아 출처표를 만든다

- 누가: 나
- 어디: 내 컴퓨터 › Code › 같은 세션 (폴더 my-course) › 입력칸

```
승인한 목차의 장마다 웹 검색으로 자료를 모아 줘.
규칙:
1. 공개 자료만, 최근 2년 자료를 먼저 쓴다.
2. sources.md 표에 번호(S1…)·제목·기관·
   발행일·주소·신뢰도(상/중/하)를 적는다.
3. 숫자는 원문 그대로, 단위와 기준연도를 붙인다.
4. 찾지 못한 것은 '미확보'로 적고 지어내지 않는다.
5. 장마다 출처 3개 이상. 다 되면 장별 개수와
   미확보 목록을 보여 줘.
```

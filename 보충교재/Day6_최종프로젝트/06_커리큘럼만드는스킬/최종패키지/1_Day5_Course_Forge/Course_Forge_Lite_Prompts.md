> 상자 오른쪽 위 **복사 버튼** → Claude 앱 **Code** 입력칸에 통째로 붙여 넣고 Enter.
> `hgd`는 **내 이니셜**, `hong-gd`는 **내 GitHub 아이디**, `kyh`·`kim-yh`는 **짝의 이니셜·아이디**로 바꾼다.

## STEP 1 — 설치와 GitHub 로그인을 프롬프트 하나로 끝낸다

- 누가: 나
- 어디: 내 컴퓨터 › Code › 방금 연 세션 (폴더: 문서) › 아래 입력칸

```
아래 순서대로 해 줘.
1. 이 폴더 안에 kma-forge 폴더를 만든다.
2. git, python3, gh 가 없으면 설치한다.
3. https://github.com/keerhee/kma-auto-genai-3-1
   을 kma-forge 안에 내려받는다.
4. 보충교재/Day6_최종프로젝트/06_커리큘럼만드는스킬/
   course-forge.zip 을 풀어 .claude/skills/course-forge
   폴더를 내 홈의 .claude/skills/ 로 복사한다.
5. GitHub 로그인을 확인하고, 안 되어 있으면
   브라우저 로그인용 일회용 코드만 알려 준다.
```

## STEP 2 — 새 세션을 열어 course-forge가 보이는지 확인한다

- 누가: 나
- 어디: 내 컴퓨터 › Code › + 새 세션 › 폴더: 문서/kma-forge › 입력칸

```
사용할 수 있는 스킬 목록에 course-forge 가
있는지 확인해 줘. 있으면 한 줄로 설명해 줘.
```

## STEP 3-1 — 실습판 크기를 정해 course-forge에 맡긴다

- 누가: 나
- 어디: 내 컴퓨터 › Code › STEP 2의 세션 (폴더: kma-forge) › 입력칸

```
/course-forge Day5 예지보전

수업 중 실습용으로 가볍게 만들어 줘.
- learn 이름: learn-pdm-lite-hgd
- 수강 시간 10분, 블록 3개만:
  B0 준비 / B1 노이즈 vs 추세 / B2 공개
- 퀴즈는 B1에 1문항만 (설비 A·B 판단)
- 대시보드는 그래프 한 장
- 원본에 없는 내용은 넣지 마.
- 승인 세 번은 짧게 요점만 보여 줘.
```

## STEP 4-1 — 새 세션에서 내 강의를 시작하고 B1 실습 글을 붙여 넣는다

- 누가: 나
- 어디: 내 컴퓨터 › + 새 세션 › 폴더: kma-forge/learn-pdm-lite-hgd › 입력칸

```
/learn-pdm-lite-hgd

(B0 준비가 끝나고 B1 설명 뒤에 검은 상자의
실습 글이 나오면, 상자 오른쪽 위 복사 버튼을
눌러 입력칸에 그대로 붙여 넣는다. 예:)

설비A와 설비B의 진동 값을 시간순 선 그래프로
그리고, 추세가 시작된 시각을 알려 줘.
```

- 누가: 나
- 어디: 내 컴퓨터 › Code › STEP 4의 세션 › 입력칸 → 카톡

## STEP 8 — 짝 강의의 점검표를 만들어 짝에게 보낸다

- 어디: 내 컴퓨터 › Code › STEP 7의 세션 (짝 강의를 들은 세션) › 입력칸 → 카톡


# course-forge 따라 하기 — 프롬프트 모음

> 각 상자 오른쪽 위 **복사 버튼**을 누르고, Claude 앱 **Code** 입력칸에 통째로 붙여 넣은 뒤 Enter.
> 여러 줄이어도 한 번에 붙여 넣는다. `내아이디`는 내 GitHub 아이디로 바꾼다.

- 누가: 나

```
지금 이 세션의 작업 폴더 경로를 알려 줘.

이 폴더 안에 kma-forge 라는 새 폴더를 만들어 줘.
앞으로 모든 작업은 kma-forge 안에서 한다.

git, python3, gh(GitHub CLI)가 설치되어 있는지
확인해서 표로 보여 줘. 없는 것은 설치해 줘.
```

```

```

## STEP 5 · 승인 ② — 정답을 실제로 실행한 결과를 확인하고 두 번째 승인을 누른다

- 누가: 나
- 어디: 내 컴퓨터 › Code › 같은 세션 › 작업이 끝나고 질문 카드가 뜬 뒤 입력칸

```
승인하기 전에 확인할게.

   브라우저로 열어 줘.
2. 원본 모범답안과 내 강의 정답 숫자를
   표 한 장으로 비교해 줘.
3. 다른 숫자가 있으면 원본 쪽수와 함께
   이유를 적어 줘.

## STEP 6-1 — 공개하기 전에 GitHub에 로그인한다

- 누가: 나
- 어디: 내 컴퓨터 › Code › 같은 세션 › 입력칸 → 저절로 열리는 브라우저

```

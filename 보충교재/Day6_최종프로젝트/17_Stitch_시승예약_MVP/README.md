# Stitch로 시승 예약 MVP 만들기

Google Stitch와 Claude Code로 모바일 시승 예약 웹앱(`testdrive_mvp.html` 한 파일)을 만드는 실습이다. 회사명·차종명·주소는 모두 실습용으로 지어낸 것이다.

| 순서 | 파일 | 내용 |
|---|---|---|
| 1 | `Stitch_MCP_Setup_Guide` (.pptx · 공개본 .pdf) | 준비 — Claude Code에 Google Stitch 연결하기(API 키 발급부터 첫 화면 생성까지), 16장 |
| 2 | `TestDrive_MVP_Build_Lecture` (.pptx · 공개본 .pdf) | 본 실습 — 화면 디자인부터 예약 저장과 테스트까지, 27장 |
| 2 | `testdrive_kit.zip` | 실습 키트 — 디자인 요청서 · 예약 규칙 · 데이터 3종 · 단계별 프롬프트 · 단계별 기대 화면 · 완성본 예시 |

Stitch 연결이 안 되면 키트 `prompts.md` 1단계의 대안으로 진행할 수 있다.

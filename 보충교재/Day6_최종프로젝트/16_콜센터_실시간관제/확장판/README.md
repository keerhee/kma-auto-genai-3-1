# 콜센터 실시간 관제 시스템 — 확장판 (STEP 0~18)

이 폴더만으로 처음부터 끝까지 진행할 수 있다. 일반판(STEP 0~11)을 먼저 하지 않았어도 된다.

| 파일 | 쓰는 때 |
|---|---|
| `CallCenter_Monitoring_Kit.zip` | 기본 키트 — STEP 0~11 (일반판과 같은 파일) |
| `CallCenter_Realtime_Monitoring_ClaudeCode_Guide` (.pptx · 공개본 .pdf) | 기본편 덱 43장 (STEP 0~11, 일반판과 같은 파일) |
| `CallCenter_Monitoring_Kit_Extension.zip` | 확장 키트 — STEP 12~18 |
| `CallCenter_Realtime_Monitoring_ClaudeCode_Guide_extension` (.pptx · 공개본 .pdf) | 확장편 덱 27장 (STEP 12~18) |
| `CallCenter_Monitoring_Reference_extension.zip` | 레퍼런스 구현 STEP 0~18 — 강사용, 수강생에게 배포하지 않는다 |

## 진행 순서

1. 빈 작업 폴더 `callcenter-monitor`에 기본 키트 zip을 두고, 덱(기본편)의 STEP 0부터 11까지 진행한다. STEP 0에서 Claude Code가 zip을 그 폴더에 푼다.
2. 확장 키트 zip을 같은 폴더에 두고, 덱(확장편)의 STEP 12부터 18까지 진행한다. STEP 12에서 Claude Code가 확장 키트를 풀어 기존 파일과 합친다.

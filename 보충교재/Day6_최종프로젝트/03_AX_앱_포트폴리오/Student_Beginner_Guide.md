# 나만의 AX 앱 포트폴리오 — 수강생 초보자 가이드

> [!summary] 한 줄 요약
> 과정이 끝나면 여러분은 **인터넷 주소 하나**를 갖게 됩니다. 그 주소에 들어가면 여러분이 회사 업무용으로 만든 앱들이 카드로 모여 있습니다. 만드는 일은 Claude Code가 하고, 여러분은 **프롬프트를 붙여 넣고 결과를 확인**만 합니다. 비용은 0원입니다.

---

## 1. 먼저 알아 둘 말 5개

| 말 | 뜻 | 비유 |
|---|---|---|
| **GitHub** | 파일을 인터넷에 보관하는 서비스 | 온라인 USB |
| **저장소(repository)** | GitHub 안의 폴더 하나. 여기서는 `ax-portfolio` | 프로젝트 폴더 |
| **커밋·푸시(commit·push)** | 바뀐 파일을 기록하고 GitHub에 올리는 것 | "저장" 후 "업로드" |
| **배포(deploy)** | 저장소의 파일을 누구나 열 수 있는 웹사이트로 만드는 것 | 게시판에 공지 붙이기 |
| **GitHub Pages** | GitHub가 무료로 해 주는 배포 서비스 | 무료 게시판 |

여러분의 사이트 주소는 이렇게 생깁니다: `https://내아이디.github.io/ax-portfolio/`

## 2. 전체 흐름 — 그림 한 장

```text
 ① 강사 템플릿 복사      ② 내 PC에서 앱 만들기       ③ 자동 배포            ④ 공유
 ─────────────────     ──────────────────────     ─────────────────     ─────────────
 강사가 만든 빈 틀을  →  Claude Code에게          →  GitHub에 올리면     →  주소를 동료·
 내 GitHub로 복사       프롬프트로 지시               1~2분 뒤 사이트에       팀장에게 보여
 (Day0, 1회)            (매일)                      자동 반영              주기
```

**여러분이 손으로 하는 일은 딱 세 가지입니다.**
1. 프롬프트 복사해서 붙여 넣기
2. GitHub 로그인·승인 버튼 누르기 (Claude Code가 "여기 누르세요"라고 알려 줄 때만)
3. 완성된 사이트 열어 보고 "이상한 곳" 말하기

## 4. Day0 — 내 포트폴리오 사이트 만들기 (30분)

Claude 앱 → **Code 탭** → 새 작업을 열고 아래를 **통째로 복사해서 붙여 넣습니다.**
`홍길동`, `품질보증팀 대리` 두 곳만 내 정보로 바꿉니다.

```text
너는 내 AX 포트폴리오 개발 파트너야. 모두 무료로 진행해.
내 이름은 홍길동, 직무는 품질보증팀 대리야.

1) keerhee/ax-portfolio-template 을 템플릿으로 내 GitHub에 ax-portfolio 라는 공개 저장소를 만들고 내 PC에 내려받아 줘.
2) GitHub Pages를 켜고 배포 방식을 GitHub Actions로 설정해 줘.
3) apps.json과 README에 내 이름·직무·사이트 주소를 넣어 줘.
4) CLAUDE.md의 공개 사이트 수칙을 점검하고 GitHub에 올려 줘.
5) 배포가 끝나면 내 사이트를 열어 확인하고, 주소를 알려 줘.
내가 직접 눌러야 하는 게 있으면 그때만 멈추고 어디를 누를지 정확히 알려 줘.
```

**이렇게 되면 성공입니다.**
- Claude Code가 `https://내아이디.github.io/ax-portfolio/` 주소를 알려 준다
- 주소를 열면 카드 10장이 보인다 (00번은 "예시", 나머지는 "기획 중")
- 00번 카드 → "앱 실행"을 누르면 설비 센서 차트가 뜬다
- 오른쪽 아래 노란 로봇(기어리)을 누르고 "이상 시점 보여줘"라고 치면 답한다

> [!tip] 중간에 멈췄다면
> 대부분 GitHub 로그인 창입니다. 브라우저에 뜬 창에서 **Authorize(승인)** 를 누르고 Claude Code에 "승인했어, 계속해"라고 쓰면 됩니다.

## 5. Day1~Day5 — 하루에 앱 하나씩 (Back 2H 시간)

그날 배운 내용으로 **내 직무에 맞는 앱 하나**를 만듭니다. 아래 틀의 `{ }` 부분만 채워서 붙여 넣습니다.

```text
CLAUDE.md의 "새 앱 추가 절차"대로 apps/{번호-영어이름}/ 에 앱을 만들어 줘.
- 문제: {내 직무}에서 {반복하는 일}을 {지금 걸리는 시간}에서 {목표 시간}으로 줄이고 싶어
- 데이터: {오늘 실습에서 쓴 데이터 파일 이름}
- 꼭 있어야 할 기능 3개: {기능1}, {기능2}, {기능3}
- 기어리도 붙여 줘.
- 다 만들면 내 사이트에 배포하고, 열어서 확인한 다음 3줄로 보고해 줘.
```

**채우는 예시 (품질 담당자, Day2)**

```text
CLAUDE.md의 "새 앱 추가 절차"대로 apps/02-recall-signal/ 에 앱을 만들어 줘.
- 문제: 품질팀에서 매주 VOC·클레임을 읽고 이상 신호를 찾는 일을 3시간에서 20분으로 줄이고 싶어
- 데이터: Day2_아이오닉5_VOC리뷰30건_가상.csv
- 꼭 있어야 할 기능 3개: 불만 유형별 건수, 갑자기 늘어난 유형 경보, 원문 보기
- 기어리도 붙여 줘.
- 다 만들면 내 사이트에 배포하고, 열어서 확인한 다음 3줄로 보고해 줘.
```

**고치고 싶을 때는 그냥 말로 하면 됩니다.**
- "차트 색을 더 진하게 해 줘"
- "표에 날짜 순 정렬 버튼 넣어 줘"
- "숫자가 이상해. 계산 기준을 화면에 써 줘"
- "고친 거 배포해 줘"

## 6. Day6 — 정리하고 발표하기

```text
내 포트폴리오를 발표용으로 정리해 줘.
1) 다 만든 앱은 apps.json에서 "운영 중"으로 바꾸고, 안 만든 앱 카드는 지워 줘.
2) README 맨 위에 앱 카드 스크린샷과 주소 표를 넣어 줘.
3) 앱마다 "전에는 몇 분 → 지금 몇 분"을 한 줄씩 정리해 줘.
4) 배포하고 주소를 알려 줘.
```

발표는 **사이트 주소를 열어 직접 보여 주는 것**으로 합니다. 평가는 과정 평가표와 같습니다.

| 평가 항목 | 보는 것 | 내가 준비할 말 |
|---|---|---|
| 도메인 적합성 40 | 내 업무 문제를 푸는가 | "이 일 때문에 매주 몇 시간이 들었다" |
| 검증 절차 30 | 결과를 믿을 수 있는가 | "정답과 비교해 몇 % 맞았다", "가상 데이터 표시" |
| 차별성 30 | 엑셀로는 안 되는가 | "주소만 주면 팀 전체가 본다", "기어리가 설명한다" |

## 7. 꼭 지킬 것 — 내 사이트는 "공개"입니다

무료로 쓰는 대신 **누구나 주소만 알면 볼 수 있습니다.** 그래서 세 가지를 지킵니다.

| 하지 말 것 | 대신 할 것 |
|---|---|
| 우리 회사 실제 BOM·단가·클레임 원문 올리기 | 과정에서 준 **가상 데이터**나 공개 자료 사용 |
| 고객사(완성차) 실명 쓰기 | `OEM_01`처럼 코드로 쓰기 |
| API 키·비밀번호를 파일에 넣기 | 기어리 설정 창에만 입력 (내 브라우저에만 저장됨) |

> [!warning] 회사 데이터로 꼭 확인해 보고 싶다면
> 공개하지 않고 **내 PC에서만** 열어 볼 수 있습니다. Claude Code에 이렇게 말하세요.
> ```text
> 내 회사 파일 {파일 경로}를 private 폴더에 복사하고, apps/{앱 폴더}를 내 PC에서만 열어 그 파일로 보여 줘.
> 확인이 끝나면 원래 데이터로 되돌리고, private 폴더가 GitHub에 안 올라갔는지 확인해 줘.
> ```
> 실수로 올려도 배포 단계에서 자동 점검이 막아 줍니다. 그래도 직접 확인하는 습관을 들이세요.

## 8. 기어리(노란 로봇) 쓰는 법

| 방법 | 어떻게 | 비용 |
|---|---|---|
| ① 바로 묻기 | "이상 시점 보여줘", "설비A 온도"처럼 짧게 쓰거나, 🎤 버튼을 누르고 말한다 | 무료 |
| ② Claude에게 묻기 | 기어리가 모르는 질문 → **Claude에게 묻기** 버튼 → 열린 Claude 창에 붙여 넣기(Ctrl+V) | 무료 (Pro 구독) |
| ③ Gemini 키 | 설정에 Gemini 무료 키를 넣으면 기어리가 직접 답함 | 선택 사항 |

> 공용 PC에서 ③을 썼다면 끝나고 **설정 → 키 삭제**를 누르세요.

**음성으로 쓰기**
- 🎤 버튼을 누르고 말하면, 말을 마칠 때 저절로 보내집니다. 처음 한 번은 브라우저가 마이크 허락을 묻습니다.
- 답을 소리로 들으려면 기어리 창 위쪽의 "음성 꺼짐"을 눌러 켭니다.
- 음성은 Chrome과 Edge에서 됩니다. 🎤 버튼이 안 보이면 지원하지 않는 브라우저입니다.
- 말소리는 브라우저 회사의 서버에서 글자로 바뀝니다. 회사 기밀은 말로 묻지 않습니다.

## 11. 2판 — "로그인해야 열리는" 사이트로 바꾸고 싶다면 (Cloudflare)

1판 사이트는 주소만 알면 누구나 봅니다. **우리 팀만 보게** 하고 싶으면 2판으로 만듭니다. 앱 만드는 방법(5절의 빈칸 프롬프트·기어리)은 똑같고, **어디에 올리고 누가 보느냐**만 바뀝니다.

| 항목 | 1판 (이 가이드) | 2판 (Cloudflare) |
|---|---|---|
| 저장소 | 공개 | 비공개 |
| 사이트 주소 | `내아이디.github.io/ax-portfolio` | `ax-portfolio-내아이디.pages.dev` |
| 누가 보나 | 주소를 아는 누구나 | 명단에 넣은 이메일만 (메일로 온 6자리 코드로 로그인) |
| 새로 만들 계정 | 없음 | Cloudflare (무료) |
| 비용 | 0원 | 0원 (도메인은 선택·유료) |

시작 프롬프트와 화면 순서는 템플릿의 `START_HERE_Cloudflare.md`와 가이드 덱 **AX 앱 포트폴리오 만들기 2 (Cloudflare)** 에 있습니다.

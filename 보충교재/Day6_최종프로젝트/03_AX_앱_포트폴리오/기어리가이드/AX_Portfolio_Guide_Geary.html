AX 앱 포트폴리오 만들기

Claude Code로 내 업무 앱을 만들고, 한 사이트에 모아 공유하는 방법

오른쪽 아래 노란 로봇 기어리에게 "다음 장", "API 키가 뭐야?"처럼 물어 보세요.

개요

포트폴리오는 사이트 하나에 앱 카드를 계속 붙여 가는 구조다

처음 한 번 사이트를 만들고, 그 뒤로는 앱을 만들 때마다 카드 한 장씩 늘어난다

하나사이트는 한 번만 만든다GitHub 저장소 하나가 포트폴리오 전체가 된다. 주소도 하나다.
둘앱은 카드로 추가한다새 앱을 만들면 첫 화면에 카드가 생기고, 누르면 그 앱이 열린다.
셋앱마다 기어리가 붙는다받은 사람이 설명서 없이 기어리에게 물어 가며 앱을 쓴다.
수강생은 프롬프트를 붙여 넣고 결과를 확인한다. 파일 만들기, 실행, 오류 해결은 모두 Claude Code가 한다.
2
개요

시작하기 전에 다섯 가지 용어를 알아 둔다

모두 이후 단계에서 그대로 쓰는 실무 용어다

용어뜻
저장소 (repository)GitHub에 올린 프로젝트 폴더. 파일과 변경 이력이 함께 보관된다.
GitHub Pages저장소의 HTML 파일을 무료로 웹사이트로 공개해 주는 GitHub 기능
README저장소 첫 화면에 보이는 설명 파일. 앱이 무엇이고 어떻게 쓰는지 적는다.
프롬프트 (prompt)Claude Code에 일을 시키는 지시문. 이 가이드의 앰버 박스가 모두 프롬프트다.
API 키프로그램이 AI 서비스를 쓸 때 내는 비밀번호. 쓴 만큼 요금이 나간다.
3
개요

작업은 다섯 단계로 진행한다

STEP 1은 한 번, STEP 2부터는 앱을 만들 때마다 반복한다

4
STEP 1 · 사이트 만들기

시작 프롬프트 하나로 사이트의 뼈대가 생긴다

아래 박스를 Claude Code에 그대로 붙여 넣는다. 이름 칸만 바꾼다

ax-portfolio라는 새 저장소를 만들어 줘. 첫 화면은 내 업무 앱을 카드로 보여 주는 허브 페이지로 하고, 제목은 "[내 이름]의 AX 앱 포트폴리오"로 해 줘. 모든 앱이 함께 쓰는 기어리 파일(shared/geary/geary.js)도 넣어 줘. GitHub Pages로 공개하고, 공개 주소를 알려 줘.
완료되면 공개 주소가 열리는지, 카드가 하나도 없는 빈 허브가 보이는지 확인한다.
5
STEP 2 · 앱 추가

빈칸 세 개를 채우면 앱 한 개가 카드로 붙는다

왼쪽은 빈칸 프롬프트, 오른쪽은 품질 담당자가 채운 예시다

새 앱을 포트폴리오에 추가해 줘. 내 업무: [ ] 쓰는 데이터: [ ] 화면에서 보고 싶은 것: [ ] 기어리도 붙이고, 허브에 카드를 만들어 줘.
새 앱을 포트폴리오에 추가해 줘. 내 업무: 프레스 라인 품질 관리 쓰는 데이터: 설비 A·B·C의 진동과 온도 로그(예시 데이터) 화면에서 보고 싶은 것: 평균에서 2σ 넘게 벗어난 시점 기어리도 붙이고, 허브에 카드를 만들어 줘.
마음에 안 드는 부분은 "차트를 막대로 바꿔 줘"처럼 말로 고친다.
6
공개 사이트 수칙

공개 저장소에는 세 가지를 올리지 않는다

GitHub Pages 주소는 누구나 열 수 있다는 전제에서 판단한다

하나회사 실데이터생산량, 불량률, 단가처럼 회사 밖으로 나가면 안 되는 숫자는 예시 데이터로 바꾼다.
둘개인정보직원 이름, 연락처, 사번이 들어간 파일은 올리지 않는다.
셋API 키키를 코드에 적으면 누구나 내 요금으로 쓸 수 있다. 키는 브라우저에만 저장한다.
회사 데이터로 확인하고 싶으면 Claude Code에 "이 앱을 내 PC에서만 열어 줘"라고 한다.
7
기어리

기어리는 질문의 종류에 따라 세 가지로 답한다

기본 기능은 API 키 없이 무료로 작동한다

명령화면을 움직인다"설비 B 온도 보여 줘", "5장으로 가 줘"처럼 말하면 해당 화면으로 바로 이동한다.
용어미리 넣은 설명으로 답한다"2σ가 뭐야?"처럼 물으면 앱을 만든 사람이 넣어 둔 정의를 보여 준다.
그 밖Claude에게 넘긴다정해진 답이 없는 질문은 지금 화면 내용과 함께 Claude에게 보내 답을 받는다.
기어리는 만든 사람이 허락한 동작만 실행한다. 임의의 코드는 실행하지 않는다.
8
기어리 · API 키

구독은 정액이고 API는 쓴 만큼 낸다

기어리에 키를 넣는 순간 요금 방식이 API로 바뀐다

구분구독 (Claude Pro 등)API 키 (Gemini 등)
쓰는 곳Claude 채팅 화면, Claude Code내가 만든 앱 안의 기어리
요금월 정액질문할 때마다 사용량만큼 청구
위험사용량 한도에 걸리면 잠시 멈춘다키가 새면 남이 내 요금으로 쓴다
대비책필요 없음키에 주소 제한과 월 지출 상한을 건다
9
문제 해결

막히면 증상을 그대로 Claude Code에 말한다

원인을 직접 찾지 않는다. 확인과 수정은 Claude Code가 한다

이럴 때Claude Code에 이렇게 말한다
공개 주소가 열리지 않는다"GitHub Pages 설정을 확인하고 공개 주소가 열리게 고쳐 줘"
새 앱 카드가 허브에 없다"허브의 앱 목록에 방금 만든 앱을 추가해 줘"
기어리가 답하지 않는다"브라우저 콘솔 오류를 확인하고 기어리를 고쳐 줘"
회사 데이터가 올라간 것 같다"저장소 이력까지 확인해서 이 파일을 완전히 지워 줘"
10
정리

공유하기 전에 여섯 가지를 확인한다

모두 체크되면 주소 하나만 동료에게 보내면 된다

  • 공개 주소가 휴대폰에서도 열리는가?
  • 만든 앱이 모두 허브에 카드로 보이는가?
  • 앱마다 기어리가 열리고 "도움말"에 답하는가?
  • 회사 실데이터 대신 예시 데이터만 들어 있는가?
  • 코드 어디에도 API 키가 적혀 있지 않은가?
  • README에 앱 설명과 사용법이 적혀 있는가?

# 텔레그램 AI 팀장 7명 — Claude Code 프롬프트 모음

작업 폴더에서 `claude`를 실행한 뒤 아래 프롬프트를 순서대로 붙여넣습니다.
봇 7개는 먼저 텔레그램 @BotFather에서 `/newbot`으로 만들고, 봇마다 `/start`를 한 번 보내 둡니다.

## ① 팀 폴더와 직무 문서

```
company 폴더에 AI 팀장 7명 조직을 만들어줘.
- 팀 폴더: strategy, marketing, sales, edu_plan, edu_ops, ai_solution, content
- 폴더마다 CLAUDE.md: 직함·담당 업무·보고 말투·하면 안 되는 일
- 전략기획실장은 대표 지시를 팀별 할 일로 나누는 역할
- shared/inbox, shared/reports, logs 폴더도 만들기
- 끝나면 폴더 구조를 보여줘
```

## ② 봇 7개 연결 (bridge.py)

```
봇 7개를 팀 폴더에 연결하는 bridge.py를 만들어줘.
- 토큰 7개와 내 chat id는 .env에서 읽기 (내가 붙여넣을게)
- 내 chat id를 모르면 첫 메시지로 알아내 줘
- 내 chat id가 아닌 메시지는 무시
- 메시지가 오면 해당 팀 폴더에서 claude -p -c 실행 후 답장
- 패키지 설치·실행·봇별 테스트까지 네가 해줘
```

## ③ 실장 → 팀 릴레이

```
전략기획실장이 내 지시를 팀별로 나눠 전달하게 해줘.
- 실장은 지시를 받으면 shared/inbox/팀명.md에 할 일을 적는다
- 각 팀은 1분마다 자기 inbox를 확인해 새 일을 처리한다
- 끝나면 결과를 shared/reports에 저장하고, 그 팀장 봇으로 나에게 보고한다
- 처리한 지시는 done 표시해 두 번 하지 않게 하고, 실장에게 진행 상황을 물으면 reports를 모아 답하게 해줘
```

## ④ 대표승인 체크표

```
매일 아침 7시에 shared/reports를 모아 '대표승인 체크표' PDF를 만들어줘.
- 표: 팀 · 한 일 · 승인 필요 사항 · 번호
- 한글이 깨지지 않게 하고 전략기획실장 봇으로 PDF를 보내줘
- 내가 '승인 3' 또는 '보류 3'이라 답하면 그 팀에 전달
- 메일 발송은 승인 전까지 초안만 만들기
```

## ⑤ 상시 실행

```
bridge.py와 팀별 inbox 확인 작업을 계속 돌게 해줘.
- 맥이면 launchd, 리눅스면 systemd로 등록 (잘 모르면 네가 골라줘)
- 멈추면 자동 재시작, 로그는 logs 폴더에 날짜별로
- 재부팅 후에도 자동 시작, 맥은 잠자기 방지 설정까지
- 지금 상태를 확인하는 방법과 멈추는 방법을 한 줄씩 알려줘
```

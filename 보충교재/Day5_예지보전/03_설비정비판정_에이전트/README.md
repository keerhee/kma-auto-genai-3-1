# 설비 정비 조치 판정 에이전트 — Day5 보충 실습

Claude Code에 프롬프트만 붙여넣어 **PdM Action Agent**(설비 정비 조치 판정 웹앱)를 만든다.
본 강의의 센서 데이터(`data/Day5`)에 정비 기준 — 진동 구간(ISO 20816-3), 제조사 한계(가상),
법정 안전검사(산업안전보건법), 사내 정비 규정(가상) — 을 더해 설비마다 A/B/C 조치를 판정한다.

| 자료 | 내용 |
|---|---|
| Day5_PdM_Action_Agent_Prompt_Guide.pdf | 가이드 덱 46장 — STEP 0~10마다 어디·입력·출력·피드백 |
| pdm_lab_data.zip | 설비 대장·기준서·사내 규정·테스트 사례 8건·상담 질문 10개·단계별 프롬프트 원문 |
| pdm_action_agent.html | 완성 예시 MVP — 설비 상황판, 매뉴얼 업로드, 정비 상담, 사용 설명서 탭. 더블클릭으로 열린다 |

- 첫 프롬프트(STEP 0)에서 Claude Code가 이 폴더의 zip을 직접 내려받는다.
- 모든 설비·인물·제조사 수치는 가상이다(한빛모터스 가상 제1공장). 안전검사 대상·주기만 실제 법령이다.
- 판정은 정비 판단을 돕는 예비 판정이며, 정지 결정은 설비 책임자가 한다.

- MVP는 파일로 열거나 GitHub Pages에 올리면 AI 설명 없이 규칙 판정과 매뉴얼 검색만으로 동작한다. PDF 업로드는 인터넷 연결이 필요하다(PDF 읽기 도구를 CDN에서 불러온다).

# 예지보전 실습 II — 붙여 넣을 프롬프트 8개

> 쓰는 법: Claude 앱 → 위쪽 **Code** → 입력칸 아래에서 **Local**과 **내 홈 폴더**를 고른다. 아래 상자를 0번부터 차례로 **통째로 복사 → 붙여 넣기 → Enter**. 처음 연 세션 하나로 끝까지 간다.
>
> 강의 덱: `PdM_Lab_Manual_II.pptx` (같은 폴더)

## 프롬프트 0 · 준비 — 작업 폴더와 데이터 4개

```
예지보전 실습 준비를 해 줘.
1. 내 홈 폴더에 kma-day5-pdm 폴더를 만들고, 그 안에 data와 outputs 폴더를 만들어 줘.
2. github.com/keerhee/kma-auto-genai-3-1 저장소의 data/Day5 폴더에 있는 csv 파일 4개를 내려받아 data 폴더에 넣어 줘.
3. Python과 pandas가 없으면 설치해 줘.
4. 파일마다 이름과 행 수를 표로 보여 줘.
```

**이렇게 나오면 성공**: 파일 4개의 행 수 50 · 50 · 4 · 6

## 프롬프트 1 · 단위 점검

```
kma-day5-pdm/data 의 '단위혼재_함정' csv를 점검해 줘. 원본은 고치지 마.
1. 앞뒤 값과 비교해 갑자기 튀는 칸을 찾고, 그 행의 '기록장치' 값을 같이 보여 줘.
2. ℉ · in/s · psi로 기록된 칸이면 ℃ · mm/s · bar로 바꿔 outputs/sensor_clean.csv 로 저장해 줘.
3. 바꾼 칸을 표로 보여 줘: 시간 | 설비 | 항목 | 기록값 → 변환값 | 기록장치
```

**이렇게 나오면 성공**: 바꾼 칸 6개(℉ 3 · in/s 2 · psi 1), 123.6℉ → 50.89℃

## 프롬프트 2 · 평상 범위

```
kma-day5-pdm/data 의 '설비센서_50건' csv로 평상 범위를 구해 줘.
1. 설비별·센서별(진동·온도·압력)로 평균과 표준편차를 구하고, 평상 범위 = 평균 ± 2 × 표준편차 를 표로 보여 줘.
2. 범위를 벗어난 값을 '이상 후보'로 표시해 outputs/anomaly_candidates.csv 로 저장해 줘.
3. 설비A 진동 선 차트에 평상 범위를 띠로 칠해 보여 줘.
```

**이렇게 나오면 성공**: 이상 후보 설비A 1점(12:40 진동 3.5), 설비B 3점(진동 2.2 · 2.9, 온도 65.1)

## 프롬프트 3 · 노이즈 vs 추세

```
같은 '설비센서_50건' csv로 이상 후보가 노이즈인지 추세인지 판정해 줘.
1. 설비별·센서별로 처음 12점(08:00~11:40)을 기준선으로 삼아 기준선 상한 = 평균 + 3 × 표준편차 를 구해 줘.
2. 상한을 3번 연속 넘으면 '추세', 넘었지만 3번 연속이 아니면 '노이즈'로 판정하고, 추세의 첫 시각을 '추세 시작'으로 outputs/trend_judgement.csv 에 저장해 줘.
3. 설비B 온도·진동 차트에 기준선 상한과 평상 범위 상한을 함께 그려 보여 줘.
4. 가장 이른 추세 시작이 평상 범위로 처음 잡힌 시각보다 몇 분 빠른지 알려 줘.
```

**이렇게 나오면 성공**: 설비B 온도 추세 시작 13:00 · 진동 15:00, 설비A는 노이즈, 160분 빠름

## 프롬프트 4 · 파일럿 선정

```
kma-day5-pdm/data 의 '공정별_파일럿평가' csv로 예지보전 파일럿 공정을 골라 줘.
1. 연간 정지손실 = 시간당 손실 × 연간 고장 건수 × 평균 정지 시간 을 다시 계산해 줘.
2. 연간 정지손실 ÷ 초기 투자(배, 소수 2자리)로 순위를 매겨 줘.
3. 고장 손실의 25%만 줄인다고 가정(추정)하고 연간 절감액과 회수 기간(년)을 계산해 줘.
4. outputs/pilot_ranking.csv 로 저장하고, 시간당 손실로만 고르면 순위가 어떻게 바뀌는지 비교해 줘.
```

**이렇게 나오면 성공**: 프레스 2.59배 1순위(조립 0.47배), 연간 절감 16,200만원 · 회수 1.5년(추정)

## 프롬프트 5 · 대시보드 만들기

```
outputs 폴더의 결과로 kma-day5-pdm/index.html 대시보드 한 장을 만들어 줘.
· 맨 위: 한 줄 요약 (가장 이른 추세 시작, 설비A 노이즈, 파일럿 1순위)
· 설비B 온도·진동 차트와 설비A 진동 차트 (기준선 상한·평상 범위 상한 표시)
· 판정표, 파일럿 순위표, data의 도입 사례 표 (출처 링크 포함)
· 맨 아래: '센서·공정 값은 실습용 가상 데이터' 표기
· 휴대폰에서도 보이게. 다 만들면 브라우저로 열어서 보여 줘.
```

**이렇게 나오면 성공**: 브라우저에 요약·차트·표가 한 화면으로 열린다

## 프롬프트 6 · GitHub Pages로 공개

```
kma-day5-pdm 폴더를 GitHub Pages로 공개해 줘.
1. 올라갈 파일 목록을 먼저 보여 주고, 개인정보·비밀번호가 없는지 점검해 줘.
2. GitHub CLI(gh)가 없으면 설치해 줘. 로그인이 안 돼 있으면 일회용 코드와 접속 주소만 보여 줘. 코드는 내가 브라우저에 직접 넣을게.
3. kma-day5-pdm 공개 저장소를 만들어 올리고 GitHub Pages(main 브랜치, 루트)를 켜 줘.
4. 배포가 끝나면 사이트 주소를 크게 보여 줘.
```

**이렇게 나오면 성공**: https://내아이디.github.io/kma-day5-pdm/ 가 휴대폰에서 열린다

## 프롬프트 7 · 보고서와 공유

```
마무리하자.
1. outputs 의 결과로 outputs/pdm_report.md 를 써 줘. 구성은 ① 현황 ② 이상 패턴과 원인(추정) ③ 정비 권고 시점 ④ 개선안. 맨 위에 '실습용 가상 데이터'라고 쓰고, 추정한 내용은 '(추정)'으로 표시해 줘.
2. README.md 에 대시보드 주소와 데이터 출처를 적고, 커밋하고 푸시해 줘.
3. 동료에게 보낼 공유 메시지를 3줄로 써 줘. 보내지는 마.
```

**이렇게 나오면 성공**: pdm_report.md 4단 + (추정) 표기, README 푸시, 공유 메시지 3줄

## 막혔을 때

| 상황 | 이렇게 붙여 넣는다 |
|---|---|
| 빨간 오류 | `방금 오류 고쳐 줘` |
| 숫자가 다르다 | `결과가 가이드와 다른데 판정 규칙부터 대조해서 원인을 찾아 줘` |
| 세션을 닫았다 | `kma-day5-pdm 폴더의 outputs를 보고 어디까지 했는지 알려 줘` |
| Pages가 404 (3분 이상) | `Pages가 404인데 원인을 찾아 줘` |

센서·공정 값은 실습용 가상 데이터다.

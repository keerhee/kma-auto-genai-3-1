# 자동차 AI 자율학습 캠프

> 16주 후, 당신의 자동차 산업 업무 방식은 영구적으로 바뀐다.

**자동차 산업 비개발 실무자**를 위한 생성형 AI 16주 집중 캠프.  
코딩 경험 없이 자연어 프롬프트만으로 모든 실습을 수행할 수 있도록 설계됨.

---

## Skills as Curriculum

이 캠프의 커리큘럼은 **Claude Skills 그 자체**다.

슬라이드를 넘기며 듣는 강의가 아니다.  
각 주차 Skill 파일을 Claude에게 제공하면, Claude가 직접 가르치고, 질문하고, 실습을 안내한다.  
매주 새로운 Skill이 열리고, 지난 주에 배운 것 위에 이번 주를 쌓는다.

```
.claude/skills/
├── week01-onboarding/    # 생성형 AI + 자동차 산업 이해
├── week02-pipeline/      # AI 업무 파이프라인 설계
├── week03-claude-code/   # Claude Code 기본 실습
├── week04-workspace/     # Google Workspace 환경 구축
├── week05-dataset/       # 자동차 산업 데이터셋 구축
├── week06-notebook/      # 데이터 분석 노트북 생성
├── week07-market/        # 자동차 시장 데이터 분석
├── week08-voc/           # 고객 리뷰(VOC) 분석 자동화
├── week09-notebooklm/    # 뉴스 분석 + NotebookLM 지식베이스
├── week10-tech/          # 자동차 기술 트렌드 분석
├── week11-competitor/    # 경쟁사 분석 자동화
├── week12-strategy/      # 전략 보고서 + AI 콘텐츠 제작
├── week13-agent/         # Automotive AI Agent Team 구축
├── week14-n8n/           # n8n 업무 자동화 워크플로
├── week15-project/       # 최종 프로젝트 개발
└── week16-graduation/    # 최종 발표 및 과정 마무리
```

## 사용 방법

**처음이면 [START_HERE.md](START_HERE.md)부터** — 준비물(계정·비용), 설치, 주차끼리 이어지는 산출물, 처음 나오는 말을 정리했다.

1. Claude 데스크톱 앱 **Code** 탭에서 이 폴더를 작업 폴더로 연다.
2. `/week05-dataset`처럼 주차 스킬을 부르거나 "5주차 수업을 시작해 줘"라고 쓴다.
3. Claude가 이론 설명 → 실습 안내 → 산출물 생성까지 전 과정을 진행한다.

5주차 데이터를 직접 만들지 못했으면 `data/`의 가상 샘플(D1 EV 판매 · D4 고객 리뷰 · D2 3사 벤치마크)로 6~8주차 · 11주차를 이어 간다.

## 과목 개요

| 항목 | 내용 |
|------|------|
| **과목명** | 생성형 AI를 활용한 자동차 산업 업무 생산성 향상 |

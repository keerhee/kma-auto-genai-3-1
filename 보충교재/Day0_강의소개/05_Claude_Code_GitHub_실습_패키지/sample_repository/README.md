# 한국 자동차 산업 AX 교육자료

자동차 산업의 생성형 AI 활용과 RAG·GraphRAG 실습 예시 저장소입니다.

## 폴더 구성
- `lectures/`: Markdown, PDF 강의노트
- `slides/`: PPT/PDF 발표자료
- `images/`: 인포그래픽 및 이미지
- `data/`: 배포가 허용된 CSV 및 예제 데이터
- `prompts/`: 실습용 Claude Code 프롬프트

## 사용법
1. `lectures/`에서 강의 내용을 읽습니다.
2. `prompts/`의 지시문을 Claude Code에 복사해 실습합니다.
3. 필요한 파일은 GitHub에서 다운로드할 수 있습니다.

> 이 문서는 **예시 템플릿**입니다. 실제 배포 전 내용을 검토하세요.

# 능률협회 자동차산업과 생성형 AI 3-1

자동차특화 AI융합 전문가 육성 과정의 강의자료입니다. 6일 과정과 로봇·스마트팩토리 특강으로 구성됩니다.

**사이트: https://keerhee.github.io/kma-auto-genai-3-1/** — 모든 덱을 PDF로 바로 보고 시뮬레이션을 실행할 수 있습니다.

## 하루의 구성

날짜 폴더마다 강의 순서대로 번호를 붙였습니다.

| 번호 | 자료 | 시간 | 역할 |
|---|---|---|---|
| 1 | Hook 케이스 | 1H | 오늘 주제를 이야기 한 편으로 여는 케이스 스토리 |
| 2 | Front 인트로 | 2H | 본 강의에 들어가기 전에 필요한 기본기와 용어 |
| 3 | Main 본 강의 | 8H | 이론과 AI 노코드 6단계 실습, 실습과제, 미니 프로젝트 |
| 4 | Back 보강 실습 | 2H | 본 강의의 틀을 "우리 회사"에 적용하는 프로젝트 2개 |

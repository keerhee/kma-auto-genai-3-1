# 5사 × 5축 마스터표 작성요령

`Day6_5사x5축_마스터표_템플릿.csv`의 빈칸을 채우는 방법이다.

| 열 | 어디서 가져오나 | 한 칸에 쓰는 것 (예시 형식) |
|---|---|---|
| 시장(1일차) | 1일차 시장·트렌드 산출물 | 지역별 판매 위치·EV 비중 한 줄 + 기준 연도 |
| 제품·고객(2일차) | 2일차 판매 Top5·VOC 키워드 | 대표 모델 + VOC 최다 불만/강점 키워드 ('예시' 표기) |
| 재무(3일차) | 3일차 재무 3대 지표 | 매출 성장률·영업이익률·R&D 비율 (연결 기준, 연도) |
| 업무혁신(4일차) | 4일차 업무분석·CS 챗봇 | 공개된 AI·자동화 도입 사례 한 줄 |
| 제조역량(5일차) | 5일차 예지보전·스마트팩토리 | 공개된 스마트팩토리·예지보전 사례 한 줄 |
| 한 줄 요약 | 위 5칸을 이어 읽은 결론 | "제품은 강하나 수익성 약점, 제조 혁신은 초기" 같은 인물상 |
| 출처 | 칸별 출처 | DART·IR·기사 링크와 기준 시점, 가상 데이터면 '예시' |

규칙

1. 데이터가 없으면 칸을 비우지 말고 **"데이터 없음"** 이라고 쓴다. 빈 칸이 곧 보완 수집 목록이다.
2. 숫자에는 기준 연도와 연결/별도 여부를 함께 쓴다. 회사마다 기준 연도가 다르면 출처 열에 적는다.
3. 2일차·4일차·5일차의 가상 데이터(아이오닉5 VOC, 한빛모터스 매뉴얼, 설비 센서 등)에서 온 내용은 **'예시'** 로 표기하고 실제 회사의 사실처럼 쓰지 않는다.
4. 행 구성은 3일차 재무 비교의 5사(현대·도요타·폭스바겐·테슬라·BYD)를 따랐다. 6일차 본 강의 12장 프롬프트는 "현대·기아·테슬라·BYD·도요타"로 되어 있으니, 반에서 정한 5사에 맞춰 행 이름을 바꿔 써도 된다.
5. 열 이름은 본 강의 12장의 [시장 위치 / 제품·고객 / 재무 / 운영 / 제조]와 같은 뜻이다(운영 = 업무혁신).

# auto_world.json: 3D 지구본 대시보드용 자동차 산업 통계

기준일: 2026-10-07. 모든 수치는 출처 원문(보도자료·공시·통계표)에서 직접 확인한 값입니다. 출처에서 찾지 못한 값은 `null`로 두었습니다.

## 기준 연도

| 항목 | 연도 | 출처 |
|---|---|---|
| 국가별 생산 | 2025 (전년 비교 2024) | OICA 2025 생산 통계표 (`prod-total-2025.pdf`) |
| 국가별 전기차 판매·비중 | 2025 | IEA Global EV Outlook 2026 / Global EV Data Explorer |
| 완성차 그룹 판매 | 2025 | 각 그룹의 보도자료·실적 공시 |

## 필드 설명

### countries (36개국)
- `production_total`: OICA 기준 2025년 전체 차량 생산 대수(승용+상용).
- `production_prev`: 같은 표의 2024년 값.
- `production_passenger`: **모든 국가 null.** OICA 2025 승용차 생산표는 웹사이트에서 상위 10개국 차트로만 공개되고, 국가별 전체 표 파일은 찾지 못했습니다.
- `ev_sales`: IEA 기준 전기 승용차 판매 대수(BEV+PHEV, FCEV 제외). IEA가 반올림해 발표한 값입니다(예: 중국 13,000,000).
- `ev_share_pct`: 신차 판매에서 전기 승용차가 차지하는 비중(%). 소수 첫째 자리로 반올림했습니다.
- `currency`: ISO 4217 통화 코드. 유로존 국가는 EUR입니다.
- `note`: 정의 차이와 결측 사유.

포함 기준: OICA 2025 표에서 생산 20만 대 이상인 30개국과, 전기차 시장으로 의미가 있는 6개국(노르웨이·네덜란드·덴마크·호주·베트남·이란)입니다.

### oems (17개 그룹, 판매 대수 내림차순)
- `sales` / `sales_year`: 그룹이 직접 발표한 판매 대수와 해당 연도.
- `definition`: 판매 정의(도매·인도·출하·회계연도 등)와 합산 방식.
- `lat`, `lng`: 본사 소재 도시 중심의 대략 좌표(소수 둘째 자리).
- `source_key`: `sources[].key`와 연결됩니다. 현대차그룹은 `hyundai2025;kia2025`처럼 두 출처를 씁니다.

## 주의 사항

1. **OICA와 각국 통계는 다릅니다.** OICA는 각국 협회(CAAM, KAMA, JAMA 등)가 제출한 값을 모은 것입니다. 국가마다 정의가 다릅니다.
   - 독일·스웨덴·네덜란드·핀란드: 승용차만 집계
   - 프랑스·아르헨티나: 승용차+경상용차(LCV)만 집계
   - OICA 표 각주에 따르면 Audi·BMW·JLR·Mercedes 일부 승용차와 Scania·Daimler Trucks·Volvo Buses 상용차는 보고에서 빠졌습니다.
   - 베트남·이란·대만은 2025 표에 개별 국가로 나오지 않습니다. "아시아 기타"에 합산되어 있어 생산은 null입니다.
2. **IEA 전기차 수치는 추정을 포함한 반올림 값입니다.** IEA는 등록 자료를 우선 쓰고, 없으면 소매 판매 자료를 씁니다. 모로코·아르헨티나·이란은 IEA 국가 데이터에 없어 null입니다.
3. **그룹 판매는 회사마다 정의가 다릅니다.** 순위 비교는 참고용으로만 쓰십시오.
   - 도요타: 다이하쓰·히노 포함 판매
   - 폭스바겐·BMW·테슬라: 고객 인도
   - 포드: 도매
   - 스텔란티스: 합작사를 포함한 출하(combined shipments)
   - GM: 10-K의 "Total Worldwide" 판매, 천 대 단위
   - 혼다: **회계연도(2025.4~2026.3)** 기준 그룹 판매, 천 대 단위
   - 현대차그룹: 현대차 도매 4,138,389대와 기아 3,135,873대를 더한 값입니다. 그룹 차원의 단일 공시치는 아닙니다. 현대차 소매 판매는 4,108,605대입니다.
   - 메르세데스-벤츠: 승용차 1,801,291대와 밴 359,136대의 합
   - SAIC: 450.7만 대로 발표되어 4,507,000으로 입력
   - 중국 업체 다수(BYD·SAIC·지리·체리)는 1차 원문 대신 회사 발표를 전한 전문 매체(CnEVPost, Gasgoo)를 출처로 기록했습니다.
4. 혼다를 제외한 모든 그룹 판매는 1~12월 기준입니다.

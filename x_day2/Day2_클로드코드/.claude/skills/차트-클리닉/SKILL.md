# 차트 클리닉 (보강 실습 A)

규칙은 `CLAUDE.md`에 있다. 여기에 다시 쓰지 않는다. 특히 §5(차트 원칙)를 따른다.

## 역할
차트를 "평가"하지 않고 목록과 **하나씩 대조**하는 검토자.

## 입력
- 기본: `input/Day2_차트클리닉_나쁜차트예시_가상.png` + `input/Day2_차트클리닉_원본데이터_가상.csv`
- 수강생 자료: 차트 이미지와 원본 표 CSV를 `working/`에 둔다. 사내 기밀 수치는 '예시'로 바꾼 뒤 쓴다.

## 절차
① 이미지를 읽고 원본 표와 함께 아래 6개 항목을 하나씩 점검한다.
   ① 메시지가 하나인가 ② y축이 0에서 시작하나 ③ 3D·장식이 비교를 방해하나 ④ 색은 강조에만 썼나
   ⑤ 판매/등록·내수/수출 기준이 섞였나 ⑥ 분모와 기간이 차트에 적혀 있나
② 진단표 저장 → `working/차트클리닉_진단표.csv`
   (열: 진단항목,원칙·함정,원본의 문제,근거,고치는 법) — 근거에는 원본 표의 숫자를 쓴다.
③ 고친 차트의 한 줄 메시지 후보 3개를 사실 → 해석 → 행동 순서로 제안하고, 수강생이 고른 것을
   `working/차트클리닉_메시지.txt` 첫 줄에 쓴다.
④ 판단 기록을 남긴다 — 진단에 쓴 원본 표와 원본 이미지를 입력으로 적는다.
   ```
   python working/scripts/stamp.py working/차트클리닉_진단표.csv [원본CSV] [원본이미지]
   python working/scripts/stamp.py working/차트클리닉_메시지.txt [원본CSV] [원본이미지]
   ```
⑤ `python working/scripts/s3_clinic.py [원본CSV] [브랜드] [원본이미지]` → `output/04_차트클리닉_전후비교.xlsx`
   인자는 `working/차트클리닉_설정.json`에 저장되어 결과화면과 전체 갱신도 같은 대상을 쓴다.
   기본값(인자 없음): input의 예시 표 · A사 · 나쁜차트 예시 이미지.
   진단 대상과 판단 기록의 입력이 다르면 멈춘다.
   기본 처리: 기준이 바뀌는 지점에서 계열을 나눠 선을 끊는다. 다른 처리가 필요하면 스크립트를 복사해 고친다.
⑥ `python working/scripts/s9_html.py` → 결과화면 ④ 탭(원본 이미지와 고친 차트를 나란히)
⑦ 역검토: "고친 차트에 남은 착시·기준 혼재"를 다시 찾아 한 줄로 보고한다.

## 흔한 감점 (먼저 피한다)
- 색·글꼴만 바꾸고 착시는 그대로 둔다.
- 기준이 섞인 숫자를 그대로 한 선으로 잇는다.
- 진단표만 있고 고친 차트가 없다.

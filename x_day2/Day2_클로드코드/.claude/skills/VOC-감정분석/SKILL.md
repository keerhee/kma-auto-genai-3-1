# VOC 감정분석 (본 강의 ③ · ⑤)

규칙은 `CLAUDE.md`에 있다. 여기에 다시 쓰지 않는다. 특히 §3(가상 표기)를 따른다.

## 역할
원 과정의 ChatGPT(생성) + Claude(분석) 역할. 고객 목소리를 빈도 데이터로 바꾸는 분석 보조자.

## 입력
- 기본: `input/Day2_아이오닉5_VOC리뷰30건_가상.csv`, `input/Day2_모델Y_VOC리뷰20건_가상.csv`
- 수강생이 "직접 생성"을 원하면: 페르소나 10명 × 1~2문장, 긍·부정이 섞이게 생성해
  `working/VOC_생성_<차종>_가상.csv`로 저장한다(열: 번호,고객유형(페르소나),리뷰).

## 절차
① **원 라벨을 보지 않고** 리뷰 원문만 읽어 분류한다.
   - 주제: 주행 · 충전 · 디자인 · 가격 · 서비스 (5개 중 하나)
   - 감정: 긍정 · 부정 · 중립
   - 키워드: 리뷰의 핵심 이유를 1~2개, 짧은 명사구로
② 같은 뜻의 키워드를 하나로 묶은 **키워드 사전**을 만든다 → `working/VOC_키워드사전.csv`
   (열: 대표키워드,감정,차종,묶은 표현)
③ **멈춤 — 사람 확인 ②**: 묶은 키워드(2건 이상 묶인 것)를 보여 주고 확정을 받는다.
④ 분류표 저장 → `working/VOC_분류.csv` (열: 차종,번호,리뷰,주제,감정,키워드 — 키워드는 `;` 구분, 대표키워드만 사용)
⑤ 판단 기록을 남긴다 — 분류에 쓴 리뷰 파일을 입력으로 적는다.
   ```
   python working/scripts/stamp.py working/VOC_분류.csv input/Day2_아이오닉5_VOC리뷰30건_가상.csv input/Day2_모델Y_VOC리뷰20건_가상.csv
   python working/scripts/stamp.py working/VOC_키워드사전.csv input/Day2_아이오닉5_VOC리뷰30건_가상.csv input/Day2_모델Y_VOC리뷰20건_가상.csv
   ```
   이 기록이 없거나 input이 바뀌면 다음 단계의 스크립트가 멈춘다.
⑥ `python working/scripts/s2_voc.py` → `output/03_VOC키워드.xlsx`
   스크립트가 사전에 없는 키워드를 발견하면 멈춘다. 사전을 고친 뒤 다시 실행한다.
⑦ 원 라벨과의 불일치 행('라벨대조' 시트)을 원문과 함께 보여 주고, 어느 쪽이 맞는지 의견을 붙인다.
⑧ `python working/scripts/s9_html.py`로 결과화면 ③ 탭을 갱신한다.

## 해석 (실습과제 3 형식)
데이터 → 해석 → 행동 순서로 4~6문장. 예:
"부정 리뷰 13건 중 7건이 충전 주제다(데이터) → 충전 경험이 불만의 중심이다(해석) → 개선 1순위는 충전 안내·앱 통합이다(행동)."
- 빈도 1건짜리 키워드로 순위를 주장하지 않는다. 주제 단위 집계를 먼저 쓴다.
- 문단 끝에 "가상 데이터(실습용) 기준"을 붙인다.
- 미니 프로젝트에서 두 차종을 비교할 때 표본 수(30 vs 20)가 다르면 건수가 아니라 비율로 비교한다.

# 주간 수집 레시피 (보강 실습 B)

규칙은 `CLAUDE.md`에 있다. 여기에 다시 쓰지 않는다. 특히 §3·§4(추측 금지, 출처 확인)를 따른다.

## 역할
한 번 잘 모은 표보다 **다음 주에도 같은 품질로 모으는 절차**를 만드는 업무 설계자.

## 처음 한 번 — 레시피 만들기
① 수강생에게 업무 하나와 대상(브랜드·품목), 주기, 보고 대상을 묻는다.
② 레시피 초안을 `output/05_주간수집레시피.md`로 쓴다. 단계마다 네 칸을 채운다.
   | 단계 | Claude Code에서 하는 일 | 붙여 넣을 프롬프트([빈칸] 표시) | 검증 체크 |
   단계: 수집 → 정리(전주 대비 변경점) → 검증 → 보고(차트 1장 + 한 줄 요약)
③ 결과 열 구성을 고정한다. 기본:
   `수집주차,브랜드,모델명,변경내용,적용일,출처,확인상태,비고`
   확인상태는 `확인됨 / 변경 없음 / 확인 필요` 셋 중 하나.
④ 시범 1회를 아래 "매주"대로 돌린다.
⑤ 절감 시간을 "손으로 할 때 N시간 → 약 M분 (추정, 시범 1회 기준)"으로 적는다.

## 매주 — 레시피 실행
① 웹 검색으로 [지난 1주] 동안 [대상]의 변경 사항을 찾는다.
② 출처 본문을 열어 적용일·금액·기준 가격(보조금 전/후)을 확인한다.
   - 매체마다 내용이 다르면 둘 다 적고 '확인 필요'.
   - 변경이 없으면 '변경 없음'. 추측으로 채우지 않는다.
③ `working/주간수집_<YYYY-Www>.csv`로 저장한다.
④ `python working/scripts/csv2xlsx.py "working/주간수집_*.csv" output/05_주간수집_누적.xlsx 주간수집`
⑤ `python working/scripts/s9_html.py` → 결과화면 ⑤ 탭
⑥ 역검토: "추측으로 채운 칸"을 다시 찾아 보고한다. '확인 필요' 행 목록을 사람에게 넘긴다.

## 예약 실행 (선택)
매주 자동으로 돌리려면 Claude Code의 예약 작업 기능으로 "주간-수집레시피 매주 실행"을 등록한다.
예약 실행도 '확인 필요' 행은 사람이 확인하기 전까지 보고서에 넣지 않는다.

# EV 시장 수집 (본 강의 ② · ④)

규칙은 `CLAUDE.md`에 있다. 여기에 다시 쓰지 않는다. 특히 §2(기준)와 §4(웹 수집)를 따른다.

## 역할
원 과정의 Perplexity 역할. 빠르게 모으되 숫자마다 기준을 확인하는 시장 조사 보조자.

## 절차
① 웹 검색으로 "국내 전기차 모델별 판매(등록) 순위 최신 월"을 찾는다. 한국어 기사·KAMA·KAIDA·국토부 자료를 우선한다.
② 후보 출처 2개 이상을 열어 본문에서 다음을 확인한다.
   - 수치가 **판매(출고)** 인가 **신규등록** 인가 — 기사 제목이 아니라 본문 표의 열 이름으로 판단
   - 기준 기간(몇 년 몇 월), 국산·수입 포함 범위, 게시일
③ 상위 5개를 `working/수집_EV_Top5_<YYYYMMDD>.csv`로 저장한다. 열 구성은 input 파일과 같게 한다.
   `순위,모델명,제조사,판매량(대),기준기간,집계기준(판매/등록),출처URL`
   (값이 등록대수여도 열 이름은 그대로 두고 집계기준 열에 '신규등록'이라 적는다. 스크립트가 열 이름을 바꾼다.)
④ `input/Day2_국내EV판매_Top5_실데이터.csv`(2026년 8월, 기준일 2026-10-07)와 비교한다.
   기간이 같으면 값 차이를, 다르면 순위 변화를 3줄 이내로 적는다.
⑤ **멈춤 — 사람 확인 ①**: 집계기준·기간·출처를 표로 보여 주고 확정을 받는다.
⑥ `python working/scripts/s1_top5.py` → `output/01_EV시장_Top5.xlsx`
   input 백업과 수집본 중 **가장 최근에 바뀐 파일**을 쓴다. 출력의 "입력:" 줄로 어느 파일을 썼는지 확인한다.
   행마다 집계기준이 섞여 있으면 멈춘다 — 사람 확인 ①로 돌아간다.
⑦ `python working/scripts/s9_html.py` → `output/00_Day2_결과화면.html` 갱신
⑧ `working/프롬프트_기록.md`에 한 줄 추가한다.

## 찾지 못했을 때
- 최신 월 자료가 없으면 찾은 가장 최근 월을 쓰고 기간을 적는다. 없는 달을 추정하지 않는다.
- 출처 두 곳의 값이 다르면 둘 다 표에 적고 확인상태를 '확인 필요'로 둔다.
- 끝내 수집이 막히면 input 실데이터를 쓰고 "백업 데이터 사용"이라고 적는다.

## 읽는 법 (차트 아래 한 줄로)
- 1위와 5위 격차, 제조사별 분포.
- "Top5 내 비중"은 시장 점유율이 아니다.

# 실습 데이터

본 강의 실습, 미니 프로젝트, 보강 실습에서 쓰는 데이터입니다. 덱에서 데이터를 쓰는 장에는 왼쪽 아래에 `실습 데이터 → data/...` 안내가 있습니다.

## 먼저 읽을 것

- **실데이터**: 실제 공시·기사·보도자료에서 옮긴 자료입니다. 행마다 출처 링크와 날짜가 있습니다. 수강생이 Perplexity로 직접 모으는 것이 기본이고, 이 파일은 수집이 막히거나 시간이 부족할 때 쓰는 **백업**입니다. 직접 모은 결과와 대조하는 검증용으로도 쓰세요. 기준일은 2026-10-07입니다.
- **가상 데이터** (`_가상`): 리뷰, 센서 로그, 매뉴얼, 메일처럼 원래 회사 내부 자료라 공개본이 없는 것입니다. 실제 기업·고객의 자료가 아닙니다. 보고서에 쓸 때는 반드시 "가상 데이터(실습용)"로 표기합니다. CS 매뉴얼과 견적 메일은 가상 브랜드 "한빛모터스" 기준입니다.
- **템플릿** (`_템플릿`): 빈 표입니다. 채워서 산출물로 씁니다.
- CSV는 UTF-8(BOM)이라 Excel과 Google Sheets에서 한글이 깨지지 않습니다. Google Sheets에서는 `파일 → 가져오기`로 엽니다.

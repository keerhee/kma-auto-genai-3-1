# Day2 수업 진행 순서 — Claude Code 운영판

원 과정(인트로 2H · 본 강의 이론 4H + 실습 4H · 보강 실습 2H)의 시간 배분은 그대로 두고,
도구 네 개(Perplexity·ChatGPT·Claude·Sheets)를 오가던 자리를 Claude Code 한 곳으로 바꿨다.
붙여 넣을 프롬프트는 `2_붙여넣는_프롬프트.md`, input을 바꾼 뒤 다시 만드는 법은 `3_input이_바뀌었을_때.md`에 있다.

## 수업 전 준비 (강사)

| 항목 | 내용 |
|---|---|
| 설치 | Claude Code 데스크톱 앱(유료 플랜), Python 3.11 이상, `pip install pandas openpyxl` |
| 배포 | 이 폴더(`Day2_클로드코드`)를 통째로 복사해 나눠 준다. `output/`의 시범 결과는 지우고 나눠도 되고, 정답 비교용으로 남겨도 된다 |
| 확인 | 수강생 PC에서 `python working/scripts/run_all.py`가 종료 코드 0으로 끝나는지 한 번 실행 |
| 웹 검색 | 회사망에서 Claude Code 웹 검색이 막히면 ② 단계는 `input/` 실데이터(백업)로 진행 |

## 본 강의 2부 실습 4H — AI 노코드 6단계

| 단계 | 시간 | 원 과정 | Claude Code 운영판 | 산출물 |
|---|---|---|---|---|
| ① 환경 | 15분 | 도구 4개 역할 배정 | 폴더 열기, `CLAUDE.md` 함께 읽기(특히 §2 기준, §7 멈추는 지점) | — |
| ② 데이터 | 50분 | Perplexity 수집 · ChatGPT 생성 | 스킬 `EV-시장수집`(웹 검색) · 가상 VOC 생성 또는 input 사용 | `working/수집_EV_Top5_*.csv` |
| ③ 전처리 | 30분 | Claude로 3열 표 | 스킬 `VOC-감정분석` ①~④ (주제·감정·키워드 분류, 키워드 사전) | `working/VOC_분류.csv` |
| ④ 분석 1 | 60분 | Sheets 막대 차트 · 도구 기준표 | `s1_top5.py` 결과 xlsx 열어 확인 · 도구 기준표 작성 | `01_EV시장_Top5.xlsx` · `02_AI도구_선택기준표.xlsx` |
| ⑤ 분석 2 | 45분 | 키워드 Top5 · 누적 막대 | `VOC-감정분석` ⑤~⑦ | `03_VOC키워드.xlsx` |
| ⑥ 평가 | 30분 | 원칙 3가지 · 절감 시간 | 결과화면 HTML로 발표 · 역검토 프롬프트 | `00_Day2_결과화면.html` |

**사람 확인 지점 3곳** (`CLAUDE.md` §7) — Claude가 멈추면 수강생이 답한다.
1. ② 끝: 수집 수치가 판매인가 등록인가, 기간은 언제인가
2. ③ 끝: 키워드 사전(같은 뜻 묶음)이 맞는가
3. ⑥ 제출 전: 가상 데이터를 사실처럼 단정한 곳이 없는가

## 미니 프로젝트 — 시장·고객 인사이트 보고서
`01`(점유율·모델 표) + `03`(아이오닉5·모델Y VOC 비교)을 근거로 임원 보고서 2~4쪽.
Claude Code에 "01과 03을 근거로 미니 프로젝트 보고서를 output/06_시장고객_인사이트.md로 써줘"라고 요청한다.
Word 파일이 필요하면 같은 내용을 docx로 바꿔 달라고 한다. 평가 루브릭(시장 진단 30 · VOC 25 · 데이터·출처 25 · 제언 20)은 그대로다.

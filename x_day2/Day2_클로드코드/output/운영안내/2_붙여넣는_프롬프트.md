# 붙여 넣는 프롬프트 — Day2 Claude Code 운영판

Claude Code 입력창에 그대로 붙여 넣는다. `[대괄호]`는 바꿔 쓰는 칸이다.
규칙(기준 표기·가상 표기·차트 원칙)은 `CLAUDE.md`에 있으므로 프롬프트에 다시 쓰지 않아도 된다.

---

## ① 환경
```
CLAUDE.md를 읽고, 오늘 지켜야 할 규칙을 5줄로 요약해줘. 멈춰서 나에게 확인받는 지점이 어디인지도 알려줘.
```

## ② 데이터 — 국내 EV Top5 (원 과정: Perplexity)
```
EV-시장수집 스킬로 국내 전기차 모델별 판매(등록) 상위 5개를 최신 월 기준으로 모아줘.
기사 제목이 아니라 본문 수치가 판매인지 등록인지 확인하고, input의 2026년 8월 자료와 비교해줘.
```

## ② 데이터 — 가상 VOC 생성 (원 과정: ChatGPT) · 선택
```
[아이오닉5] 고객 페르소나 10명을 만들고 각자 입장에서 실제 같은 리뷰를 1~2문장씩 써줘.
긍정·부정이 골고루 섞이게 하고 working/VOC_생성_[아이오닉5]_가상.csv로 저장해줘.
```
생성하지 않고 `input/`의 가상 리뷰 30건·20건을 써도 된다.

## ③ 전처리 + ⑤ 분석 2 — VOC 감정분석
```
VOC-감정분석 스킬로 input의 아이오닉5 리뷰 30건과 모델Y 리뷰 20건을 분석해줘.
원 라벨은 보지 말고 원문만 읽어 분류한 다음, 키워드 사전을 먼저 보여줘.
```
사전을 확인한 뒤:
```
사전 확정. 계속 진행해서 xlsx와 결과화면을 만들고, 원 라벨과 다른 행을 원문과 함께 보여줘.
```

## ④ 분석 1 — AI 도구 선택 기준표
```
데이터 수집 목적(최신 뉴스 / 가상 데이터 생성 / 분석·구조화 / 고치는 표 / 보여 주는 화면)별로
Claude Code 안에서 무엇을 쓰는지 [목적 / Claude Code 안의 도구 / 원 과정 도구 / 이유 / 주의점] 표로 만들어
working/AI도구_선택기준표.csv로 저장하고 output/02_AI도구_선택기준표.xlsx로 만들어줘.
주의점 열에는 각 도구의 약점을 꼭 적어줘.
```

## ⑥ 평가
```
오늘 만든 01·02·03 결과를 종합해
① 목적별 도구 선택의 핵심 원칙 3가지
② 이 방식으로 줄어든 업무 시간 추정(추정 근거 포함)
을 정리해줘.
```

## 제출 전 역검토 (사람 확인 ③)
```
output의 결과물에서 (1) 가상 데이터인데 사실처럼 단정한 문장 (2) 기준·기간·출처가 빠진 숫자
(3) 상관을 인과처럼 쓴 문장을 찾아 표로 보여줘. 고치지는 말고 목록만.
```

# input이 바뀌었을 때 — 결과를 다시 만드는 법

## 한 줄 요약
`input/`의 파일을 바꿔도 결과는 **자동으로 바뀌지 않는다.** Claude Code에 아래 한 줄을 붙여 넣는다.

```
input을 바꿨어. Day2-전체갱신 스킬로 결과를 다시 만들어줘.
```

## 무엇이 어떻게 다시 만들어지나

| 산출물 | 누가 만드나 | input이 바뀌면 |
|---|---|---|
| 00 결과화면 | 스크립트 | 바로 다시 만든다 |
| 01 EV 시장 Top5 | 스크립트 | 바로 다시 만든다 |
| 02 도구 기준표 | Claude가 작성 (input과 무관) | 그대로 |
| 03 VOC 키워드 | **Claude가 리뷰를 읽고 분류** | Claude가 리뷰를 처음부터 다시 읽고 분류한다. 키워드 사전 확인(사람 확인 ②)을 다시 한다 |
| 04 차트 클리닉 | **Claude가 차트를 읽고 진단** | Claude가 다시 진단한다. 한 줄 메시지를 다시 고른다 |
| 05 주간 수집 누적 | 스크립트 | 바로 다시 만든다 |

03·04처럼 Claude가 판단한 결과는 스크립트를 다시 돌려도 바뀌지 않는다.
그래서 판단할 때마다 **어떤 input을 보고 판단했는지** 기록해 두고(`working/_판단기록.json`),
input이 바뀌면 그 결과를 쓰지 않고 멈춘다.

## 갱신 중에 보게 되는 것
- **"다시 판단 필요"**: input이 바뀌어 예전 판단을 쓸 수 없다는 뜻이다. Claude가 해당 스킬을 다시 진행한다.
- **결과화면의 "갱신 대기" 표시가 붙은 "다시 판단 필요" 카드**: 그 탭은 아직 다시 판단하지 않았다는 표시다. 이 상태로 발표·배포하지 않는다.
- **`output/_이전판/`**: 예전 input으로 만든 03·04 파일을 지우지 않고 옮겨 둔 곳이다. 비교용으로만 보고 배포하지 않는다.
- **`[중단] 집계기준이 하나로 정해지지 않음`**: 새 Top5 표에 판매 기준과 등록 기준이 섞여 있다는 뜻이다. 어느 기준으로 통일할지 정해 준다.

## 자주 묻는 것
**Top5를 웹에서 새로 모았는데 input 파일도 바꿨다. 어느 쪽이 쓰이나?**
둘 중 **가장 최근에 바뀐 파일**이 쓰인다. 결과 xlsx 아래 노트의 "입력 파일:" 줄에 어느 파일을 썼는지 적힌다.

**리뷰 몇 줄만 고쳤는데도 다시 분류해야 하나?**
그렇다. 한 줄이라도 바뀌면 주제별 건수와 키워드 순위가 달라질 수 있다.
번호는 같고 내용만 바뀐 경우도 스크립트가 원문을 대조해 잡아낸다.

**갱신 이력은 어디서 보나?**
`working/갱신기록.md` — 실행 시각, 바뀐 input, 다시 만든 산출물, 다시 판단할 항목이 한 줄씩 쌓인다.
